# Project background

`libssh2-swift` is a cohesive Swift Package wrapper for the SSH2 protocol and SFTP services, backed by the high-performance AWS-LC cryptographic library. It powers MacSSH with modern async/await networking.

## Goals
- Modern, async/await Swift interface over libssh2.
- High-performance cryptography powered by AWS-LC on Apple Silicon.
- Full SFTP client implementation with directory streaming and file transfers.
